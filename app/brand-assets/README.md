# خروجی لوگوی بیترو‌لرن

این تصاویر از لوگوی اصلاح‌شدهٔ فعلی، با فونت محلی و فاصلهٔ مناسب خط مورب از دو علامت کناری تولید شده‌اند.

- فایل `index.html` گالری و پیوند دریافت هر اندازه است.
- فایل `bitrolearn-logo-sheet.png` تابلوی معرفی حالت‌هاست.
- فایل `manifest.json` ابعاد، اندازه و اثرانگشت خروجی‌ها را ثبت می‌کند.
- نسخه‌های دارای `transparent` زمینهٔ شفاف دارند؛ عنوان `dark` یا `light` رنگ نوشتهٔ مناسب همان پس‌زمینه را مشخص می‌کند.
- خروجی نشان تا ۲۰۴۸ پیکسل و لوگوی کامل تا ۳۲۰۰ پیکسل ارائه شده است.
- برای بازتولید، دستور `node scripts/export-brand.mjs` را از پوشهٔ اپ اجرا کنید.

منبع برداری در فایل‌های `app/src/components/logo.tsx` و `app/src/app/icon.svg` باقی مانده است. این خروجی‌ها جایگزین لوگوی مورد استفاده در رابط نشده‌اند.

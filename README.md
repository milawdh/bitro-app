# بیترو‌لرن

این مخزن شامل دو فرانت مستقل برای یادگیرنده و مدیریت محصول و بک‌اند مستقل با دات‌نت ۱۰ است. فرانت‌ها فعلاً به بک‌اند متصل نیستند.

## گزارش فنی و منابع طراحی

- گزارش کامل فارسیِ نیازمندی‌ها، ابزارها، معماری و دامنهٔ بک‌اند، راه‌حل‌ها، ساختار پیشنهادی و تسک‌های مرحله‌بندی‌شده در فایل [نقشهٔ بک‌اند](backend-blueprint.html) قرار دارد.
- مرجع رنگ‌ها، فونت‌ها، توکن‌ها، اجزای رابط و قواعد طراحی در فایل مستقل [دیزاین سیستم](design-system.html) است.
- گالری و دریافت خروجی‌های لوگو در فایل [کتابخانهٔ لوگو](app/brand-assets/index.html) و بستهٔ [همهٔ تصاویر](app/brand-assets/bitrolearn-logos.zip) قرار دارد.

هر دو گزارش با فونت‌های تعبیه‌شده، بدون اینترنت و مستقیماً در مرورگر باز می‌شوند. بک‌اند تا تسک هفت، شامل دوره و پرداخت، پیشرفت، پیش‌نویس، تصحیح سروری و کش محتوا پیاده شده است. راهنمای فنی در [راهنمای بک‌اند](backend/README.md)، جزئیات مرحلهٔ جدید در [راهنمای یادگیری و کش](backend/LEARNING.md) و قواعد انگلیسی توسعه در [سیاست رابط](backend/API-POLICY.md) هستند.

```text
bitro-app/
├── app/       # فرانت یادگیرنده
├── admin/     # استودیوی مدیریت
├── backend/   # رابط مستقل دات‌نت ۱۰، دیتابیس و ورود
├── compose.yaml
└── README.md
```

## اجرای داکر

از روت مخزن اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File backend/scripts/Initialize-LocalEnv.ps1
docker compose --env-file backend/.env up --build -d frontend admin backend-gateway backend-worker backend-storage-gateway
docker compose --env-file backend/.env ps
```

- نشانی اپ: http://localhost:3000
- نشانی ادمین: http://localhost:3001
- نشانی بک‌اند: http://localhost:7075
- نشانی مستندات: http://localhost:7075/scalar
- نام کانتینر اپ: `bitro-frontend`
- نام کانتینر ادمین: `bitro-admin`

هر دو فرانت با ساخت تولیدی، کاربر غیرریشه و بررسی سلامت اجرا می‌شوند. فایل هماهنگی نام سرویس قبلی اپ را حفظ می‌کند و سایر سرویس‌های موجود روی سیستم را مدیریت نمی‌کند.

```sh
docker compose --env-file backend/.env logs -f admin
docker compose --env-file backend/.env logs -f frontend
docker compose --env-file backend/.env logs -f backend-api
docker compose --env-file backend/.env down
```

## توسعه و بررسی

برای توسعهٔ اپ:

```sh
cd app
npm ci
npm run dev
```

برای توسعهٔ ادمین، در ترمینال جداگانه:

```sh
cd admin
npm ci
npm run dev -- --port 3001
```

هر فرانت فایل بسته‌ها، فایل قفل، سورس، منابع و تست‌های مستقل دارد. فونت‌ها و منابع ویرایشگر کد محلی هستند و به سرویس پولی یا کلید دسترسی نیاز ندارند.

برای بررسی، در پوشهٔ هر فرانت اجرا کنید:

```sh
npm run typecheck
npm run lint
npm test -- --maxWorkers=2
npm run build
npm run test:e2e
```

تست مرورگر به اجرای هر دو فرانت و نصب مرورگر کروم نیاز دارد. ساخت داکر نیز بررسی نوع‌ها، بررسی کد و تست‌های منطقی همان فرانت را اجرا می‌کند.

## مرز نسخهٔ نمایشی

فضای ادمین شامل داشبورد، مدیریت دوره و درس، آزمایشگاه‌های موجود، چالش‌ها، قالب پروژه، یادگیرنده‌ها، گزارش‌ها، تنظیمات و ورود آزمایشی است. داده‌های اولیه از محتوای فعلی اپ گرفته شده‌اند و آمار کاربران، دادهٔ نمونه است.

ذخیرهٔ فرانت ادمین با پیشوند `bitro-admin-*` از ذخیرهٔ اپ مستقل است. انتشار، تعلیق کاربر و تغییر نقش در فرانت فعلی فقط در پیش‌نمایش آن اثر دارد. بک‌اند ورود واقعی و دیتابیس خودش را دارد و اتصال فرانت‌ها تسک بعدی است.

بازنشانی ادمین، محتوا و داده‌های نمونه و پیش‌نویس‌های آن را بازیابی می‌کند و تنظیمات شخصی پنل را نگه می‌دارد. این عملیات اطلاعات یا پیشرفت اپ را تغییر نمی‌دهد.

ساخت، مایگریشن، تست و اجرای بک‌اند همگی در داکر انجام می‌شوند. حساب‌های مدیریتی و نقش‌ها از کاربران پیامکی اپ مستقل‌اند؛ مشخصات اولیهٔ سوپریوزر در فایل محلی و نادیده‌گرفته‌شدهٔ `backend/.env` قرار دارد.
